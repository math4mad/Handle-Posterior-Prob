Bayesian Inference · Interactive

Posterior probabilities are a knob.

Turn them to adjust a model's sensitivity to the data. This project recreates Murphy (2022) Fig 3.9 — Bayesian inference for a 2D Gaussian — plus a two-stage 1D Gaussian cockpit, driven by GarageBand-style rotary controls.

⭐ View on GitHub Run it locally

Two knobs, one posterior

Stage 1 · μ₀ — localize

Slide the prior mean toward where the data roughly live. The posterior is pulled between the prior and the sample mean — coarse positioning first.

Stage 2 · σ₀ — envelope

Fine-tune the prior width. Wide σ₀ lets the data dominate; narrow σ₀ pins the posterior near μ₀. The conjugate update is exact: σ²_post = (1/σ₀² + N/σ²)⁻¹.

2D · PRML Fig 3.9

Data ~ N(z, Σy), prior N(0, 0.1 I). Turn the sensor-noise knob: small σ → the posterior snaps onto the data; large σ → it collapses back onto the prior.

🎛️ Real rotary knobs

The Streamlit app uses Knob.js via Custom Components v2 — drag to spin, slide like a fader, or scroll. The hero animation above is rendered with Remotion.

Run it locally

  1. git clone https://github.com/math4mad/Handle-Posterior-Prob.git
  2. cd Handle-Posterior-Prob
  3. pip install streamlit plotly numpy
  4. streamlit run app.py
